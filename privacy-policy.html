Privacy Policy for Ratan Industries

Effective date: September 20, 2026

Important: Ratan Industries is a customized and modified version of the InvenTree mobile application for authorized Ratan Industries staff. This application is not the official InvenTree mobile application and is independently branded, configured, and distributed by Ratan Industries.

1. About This Application

The Ratan Industries mobile application ("App") is a customized and modified version of the open-source InvenTree mobile application. It is used by authorized Ratan Industries staff to connect to an InvenTree stock management server and perform inventory-related tasks.

The App includes Ratan Industries branding, a staff access gate, and configuration for use with the Ratan Industries InvenTree environment.

This App is not affiliated with, endorsed by, or supported by the official InvenTree project unless explicitly stated otherwise.

2. Information Stored on the Device

For each InvenTree profile configured in the App, information required to connect and authenticate with the selected InvenTree server may be stored locally on the device.

This may include:

  • Server name
  • Server address
  • An InvenTree API authentication token

3. User Authentication

The App uses an InvenTree API token for user authentication. The token is obtained from the connected InvenTree server after the user provides their login credentials.

The username and password entered during authentication are used to request the API token. They are not intended to be stored locally or used for other purposes.

A separate API token may be stored locally for each configured InvenTree profile. The stored token can be removed from the App's settings, after which the user may need to enter their login credentials again.

An API token may also be revoked by the connected InvenTree server or may expire. In that situation, the user may be required to authenticate again.

4. Ratan Industries Access PIN

The App may require an access PIN before allowing use of the application. This access gate is intended to restrict the App to authorized Ratan Industries staff.

The access PIN is an application access control and is separate from the user's InvenTree account credentials.

5. Camera Permission

The App may request access to the device camera for supported inventory functions, including:

  • Scanning barcode data
  • Scanning QR codes where supported
  • Taking pictures for upload to the connected InvenTree server where the relevant InvenTree functionality is used

Camera access is used when the relevant feature is invoked. The App does not use the camera for continuous recording.

6. Inventory and Business Data

When the App connects to an InvenTree server, it may display or transmit information relating to inventory and stock management. Depending on the user's permissions, this may include parts, products, stock quantities, stock locations, barcode information, and other records available through the connected InvenTree server.

Such information is handled by the connected InvenTree server according to the configuration and policies of the organization operating that server.

7. Personal Information

The App is not designed to collect personal information for advertising or marketing purposes.

Information associated with an InvenTree user account may be processed when required to authenticate the user and provide the functionality of the connected InvenTree service.

8. Third-Party Access and Sharing

Ratan Industries does not sell personal information collected or processed through the App.

Information may be transmitted to the configured InvenTree server when required to provide inventory and stock-management functionality. The connected server may be operated by Ratan Industries or by an organization authorized by Ratan Industries.

Information may also be disclosed where required by applicable law or where necessary to protect the security and integrity of the App or associated systems.

9. Error Logs and Crash Reporting

The underlying InvenTree mobile application may use Sentry or another error-reporting service to collect technical information about application errors and runtime failures.

Where error reporting is enabled in this version of the App, technical error information may be transmitted to the configured error-reporting service to help diagnose bugs and improve application reliability.

Error reports are intended to contain technical information about the application failure, such as where an error occurred in the application code. They are not intended to collect passwords, API authentication credentials, or inventory records for debugging purposes.

If the installed version of the App provides an error-reporting setting, users may be able to disable error reporting through the App's settings.

10. Data Security

Reasonable technical and organizational measures are used to protect information handled by the App and associated systems. Users should protect their InvenTree credentials, API access, and application access PIN and should not share them with unauthorized persons.

The security of information transmitted to an InvenTree server also depends on the configuration and security of that server and its network connection.

11. Data Retention and Deletion

Local authentication information, including stored API tokens, may remain on the device until removed through the App, the associated profile is removed, or the application data is cleared or the App is uninstalled.

Inventory and account information stored on the connected InvenTree server is retained according to the policies and configuration of the organization operating that server.

For requests concerning deletion, correction, or access to information maintained by the Ratan Industries InvenTree server, contact your Ratan Industries IT or system administrator.

12. Children's Privacy

The App is intended for authorized Ratan Industries staff and is not directed toward children. The App is not intended to knowingly collect personal information from children.

13. Third-Party Software

The App is based on the open-source InvenTree mobile application and uses third-party libraries and software. Applicable license and attribution information may be available within the App under Settings → About → Licenses.

14. Changes to This Privacy Policy

This Privacy Policy may be updated when the App, connected services, data practices, or applicable requirements change. The effective date shown at the top of this page indicates the date of the current version.

15. Contact

For privacy questions, data requests, account issues, or questions about access to the Ratan Industries InvenTree server, contact your Ratan Industries IT or system administrator.

16. InvenTree Relationship

The Ratan Industries App is a customized and modified version of the InvenTree mobile application. InvenTree is an open-source inventory management system. This Ratan Industries application is independently branded and distributed and should not be represented as the official InvenTree mobile application.
